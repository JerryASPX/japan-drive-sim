# 日本自駕情境模擬教學（台灣人・繁體中文）

給台灣駕駛的日本自駕行前練習：用情境題＋實景照片，熟悉日本交通標誌、靠左行駛、加油、停車、事故處理等常見狀況。

## 線上玩
https://jerryaspx.github.io/japan-drive-sim/

## 本機玩
下載或 clone 本 repo，直接用瀏覽器開 `index.html` 即可（不需安裝、不需伺服器）。

## 技術
- 純靜態網頁：HTML + CSS + 原生 JavaScript
- 題庫：`data.js`；實拍照片：`footage-data.js`
- 外觀：Bootstrap 5 + Bootswatch Zephyr 主題（從 CDN 載入）
- 部署：GitHub Pages（main 分支根目錄）

## 注意
- 版面樣式走 CDN，**需要連網**；離線時功能可用但外觀會跑掉。
- 情境插圖為 AI 生成，僅供教學參考；實際規定以日本官方資訊為準。
